# 游戏相机惯性滑行辅助工具

这个项目最初是为了解决原神留影机的键盘模式没有惯性滑动的问题而做的，就是让移动按键松开后继续滑一小段、再缓缓停住，拍出更自然的运镜效果。做着做着发现应该可以拓展应用在很多其他游戏甚至工作，遂开了它。

它只做一件事：**松开移动键之后，代替你继续按这个键，按的时间比例按曲线递减，
从而让目标程序产生“平均速度逐渐下降、最后缓缓停住”的视觉效果。**但是这个只在低速运镜效果比较好，移动速度太大会导致有阶梯感。

## 作用

- **物理按住** WASD时，按键原样透传给游戏，目标程序照常匀速移动。
- **物理松开** 按键后，本程序在"滑行窗口"内代替你继续向系统注入该键的短按，
  注入频率/占空比随时间递减，产生平滑减速直至停住的视觉惯性效果。
- 鼠标输入不管，完全透传。

## 工作原理（PWM魅力时刻）

原神按帧采样按键（桌面锁 60fps ≈ 16.7ms/帧），键松开的下一帧就会停。
要做出"松开后还滑一段、慢慢停住"的效果，程序在滑行阶段持续伪造按键脉冲：

```
按下(hold) → 停(gap) → 按下(hold) → 停(gap) → ……
```

衰减曲线输出的"速度权重" `w` 控制脉冲的占空比（按的时间比例）：

- 刚松手 `w≈1`：几乎一直按着 → 目标程序匀速走；
- 滑行后期 `w→0`：按 1 帧停 4 帧 → 平均速度越来越低 → 缓缓停住。

## 编译

就一个.c，随便。

## 运行

```
camera_inertia.exe            # 使用默认参数
camera_inertia.exe config.ini # 或传入配置文件
```

按 **ESC** 或关闭窗口退出。

## 配置说明（config.ini）

每行 `key = value`，`#` 开头为注释。所有参数均可省略，省略时使用默认值。

| 参数 | 默认 | 说明 |
|------|------|------|
| `slide_ms` | 1200 | 滑行总时长（毫秒）。越大滑得越远 |
| `game_fps` | 60 | 目标程序逻辑帧率，用于让"走/停"对齐整帧，录屏时位移更均匀 |
| `base_hz` | 180 | 基础脉冲频率（Hz）。越高阶梯越细，但过高手感越"糊" |
| `min_hold_ms` | 2 | 单次注入脉冲最小保持时长（毫秒），即虚拟按键按下的最短时间 |
| `min_gap_ms` | 1 | 两次脉冲之间最小间隔（毫秒） |
| `max_slide_frames` | 5 | 减速时"走"的帧数上限（保留字段，当前逻辑不再主导） |
| `curve` | 4 | 衰减曲线，见下表 |
| `keyW`/`keyA`/`keyS`/`keyD` | 87/65/83/68 | 移动键虚拟键码，默认 W/A/S/D |
| `keyUp` | 32 | 上升键（空格），`-1` 禁用 |
| `keyDown` | 160 | 下降键（左 Shift），`-1` 禁用 |
| `enableReplay` | 1 | 是否注入"模拟按下"到目标程序；`0` 仅透传不重放（滑行功能失效） |

### 衰减曲线

| 值 | 名称 | 效果 |
|----|------|------|
| 0 | 线性 | 从 1 匀速降到 0 |
| 1 | 指数 | exp 衰减，前期快后期慢，收尾柔和 |
| 2 | 前后平滑 | 两端速度都为 0（C1 连续），松手不掉速、收尾也缓，滑行最持久 |
| 3 | 缓出余弦 | 松手瞬间几乎不掉速，缓缓减速 |
| 4 | 缓出平方（默认） | 开头掉速最快，末尾平滑收尾，整体干脆不拖 |

## 注意事项

- 按键是 0/1 离散信号，本方案靠"走/停"占空比模拟减速，有些情况下效果不佳。高手使用手柄是更好的选择。
- 本程序不修改任何目标程序文件，不写游戏内存，完全不触发反作弊。
